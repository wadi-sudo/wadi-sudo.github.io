Connect Google Earth Engine

Earth Engine needs a one-time setup. No paid API key is required, only an OAuth Client ID.

  1. Open console.cloud.google.com, create a project, and note its Project ID.
  2. Register that project for Earth Engine at code.earthengine.google.com/register (choose Noncommercial).
  3. APIs & Services, Library: enable Earth Engine API.
  4. OAuth consent screen: type External, add your email as a test user.
  5. Credentials, Create credentials, OAuth client ID, type Web application. Under Authorized JavaScript origins add https://YOURNAME.github.io and http://localhost:8000.
  6. Paste the Client ID and Project ID into the EDIT HERE block at the top of index.html, then reload.
