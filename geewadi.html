Data honesty notice. Imagery dates are real. Analysis figures labelled ILLUSTRATIVE are sample values for demonstration and are not derived from satellite pixels. When live pixel access succeeds, the badge changes to LIVE and figures come from the loaded imagery.
Method
Visual change: per-pixel RGB Euclidean distance on a downsampled 3×3 tile mosaic. Vegetation proxy: excess green (2G−R−B). Built-up proxy: mean brightness. These are not calibrated NDVI/NDBI. True NDVI/NDBI requires a Sentinel Hub instance ID in CONFIG.sentinelHub.instanceId.
